# 교사용 과제 채점 리포트 API — 요구사항 스펙

- 문서 상태: 초안 v0.1 (기획팀 작성, 개발 검토 전)
- 대상: 백엔드 API 하나. 화면은 이번 범위가 아니다.

## 1. 배경과 목적

교사는 과제를 배포한 뒤 "누가 냈는지, 점수가 어떤지"를 확인하려고 학생별 제출 목록을 하나씩 열어 본다. 학급이 여러 개인 교사는 과제 하나를 확인하는 데 시간이 오래 걸린다. 마감을 넘겨 낸 제출이 섞여 있으면 그것까지 하나씩 가려 봐야 한다.

이번에 만드는 API는 **과제 하나에 대한 채점 리포트**를 한 번의 호출로 돌려준다. 교사용 화면(별도 과제)이 이 API를 호출해 리포트를 그린다.

## 2. 기능 요구사항

### 2.1 과제별 채점 리포트 조회

이번 개발의 핵심 기능이다. 교사는 과제 하나를 지정해 그 과제의 채점 리포트를 조회한다.

리포트에는 다음 요약 값이 들어간다.

- 과제 정보: 과제 ID, 과제 제목, 학급 ID, 마감 시각
- 대상 학생 수: 그 학급에 속한 학생 수
- 제출 건수와 미제출 건수, 그중 지각 제출 건수(3.3 참고)
- 평균 점수, 최고 점수, 최저 점수

### 2.2 학생별 제출 현황

리포트에는 요약 값과 함께 학급의 학생별 현황 목록이 들어간다. 학생 한 명이 한 행이다.

- 학생 ID, 제출 여부, 점수, 제출 시각
- 지각 제출이면 그 사실이 행에 표시된다(3.3 참고)
- 과제를 내지 않은 학생도 목록에 나온다

목록은 학생 ID 순으로 정렬한다.

### 2.3 조회 권한

- 교사는 **자신이 담당하는 학급**의 과제에 대해서만 리포트를 볼 수 있다.
- 한 교사가 여러 학급을 담당할 수 있고, 한 학급의 담당 교사는 한 명이다.
- API는 요청마다 요청한 교사가 누구인지 알 수 있어야 한다. 로그인 · 토큰 같은 인증 방식은 별도 과제이므로, 이번에는 요청에 교사 ID가 함께 실려 온다고 보고 만든다.

## 3. 도메인 규칙

### 3.1 용어

| 용어 | 설명 |
|---|---|
| 학급 | 학생들의 묶음. 담당 교사가 한 명 있다 |
| 과제 | 학급 하나에 배포된다. 제목과 마감 시각이 있다 |
| 제출 | 학생이 과제에 낸 답안 한 건. 제출 시각과 점수가 있다 |
| 채점 리포트 | 과제 하나에 대한 요약 값과 학생별 현황(2.1 · 2.2) |

식별자는 문자열이다. 예: 과제 `A1`, 학급 `C1`, 교사 `teacher-01`, 학생 `S001`.

### 3.2 점수

- 점수는 0점 이상 100점 이하의 정수다.
- 채점은 이 API 밖에서 이미 끝나 있다. 이 API가 다루는 제출에는 모두 점수가 붙어 있다.

### 3.3 마감과 지각 제출

- 과제에는 마감 시각이 있다.
- 마감 시각이 지난 뒤에도 학생은 제출할 수 있다. 이런 제출은 **지각 제출**로 표시된다.

### 3.4 재제출

- 학생은 같은 과제를 여러 번 제출할 수 있다. 제출할 때마다 새 제출 기록이 남고, 각 제출에 점수가 매겨진다.
- 학생별 현황(2.2)에는 학생 한 명당 한 행만 나온다.

## 4. 비기능 요구사항

- 응답은 JSON이다.
- 외부 DB나 외부 서비스 없이 시작 골격에 설정된 저장 방식으로 돈다.
- 학급 하나의 학생 수는 40명 이하로 본다. 조회는 빠르게 응답해야 한다.

## 5. 수용 기준

- **5.1** 담당 교사가 과제의 채점 리포트를 조회하면 제출 건수와 평균 점수가 정상적으로 반환된다. (2.1)
- **5.2** 평균 점수는 보기 좋게 적절히 반올림해서 보여 준다. (2.1)
- **5.3** 과제를 내지 않은 학생도 학생별 현황에 나오고, 미제출로 표시된다. (2.2)
- **5.4** 지각 제출은 학생별 현황에서 구분할 수 있다. (2.2, 3.3)
- **5.5** 아직 아무도 제출하지 않은 과제도 리포트를 조회할 수 있다. (2.1)
- **5.6** 교사는 담당하지 않는 학급의 리포트를 볼 수 없다. (2.3)
- **5.7** 요청한 교사를 알 수 없는 요청은 처리하지 않는다. (2.3)
- **5.8** 존재하지 않는 과제를 조회하면 적절한 오류를 반환한다. (2.1)

## 6. 범위 밖

- 채점 자체와 점수 수정
- 학생 · 학부모용 조회
- 로그인 · 토큰 등 인증 방식 (2.3의 "요청에 교사 ID가 실려 온다"로 대신한다)
- 여러 과제를 합친 학급 · 학기 단위 리포트
- 리포트 내보내기(CSV · PDF), 화면
